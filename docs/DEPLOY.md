# Деплой Home.Media (Zero-config)

Проект полностью оптимизирован под Synology Container Manager и не требует ручных манипуляций с конфигурационными файлами или скриптами.

## Шаги деплоя

1. **Скачайте код**: скопируйте файлы репозитория в папку на вашем NAS (например, `/volume1/docker/hm3-syn/`).
2. **Container Manager**: зайдите в "Проекты", нажмите "Создать" и укажите путь к этой папке.
3. **Deploy**: Container Manager автоматически прочитает `docker-compose.yml`. Не нужно создавать `.env` файлы — всё сгенерируется автоматически.
4. **Первый вход**: Перейдите по адресу `http://ВАШ_IP:8142`.
5. **Setup**: При первом входе вы увидите страницу `Setup`, где нужно задать логин и пароль первого администратора.

### Технические детали
- `docker-entrypoint.sh` генерирует `SECRET_KEY` и запускает Alembic-миграции.
- База данных (PostgreSQL) поднимается автоматически.
- Все системные настройки (включая порты плагинов) настраиваются на вкладке "Settings" в веб-интерфейсе.
