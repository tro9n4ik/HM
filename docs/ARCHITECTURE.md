# Архитектура Home.Media

Ядро `home-media-core` (FastAPI) работает как управляющий узел:
- Раздаёт статику админки (React)
- Управляет БД (PostgreSQL через SQLAlchemy / Alembic)
- Обслуживает reverse-proxy для плагинов

## База Данных

- **User**: администраторы системы.
- **Plugin**: зарегистрированные плагины (состояние, порт, пути).
- **PluginConfig**: конфигурация плагинов (включая секреты).
- **SystemSetting**: системные переменные, настраиваемые через UI.

## Жизненный цикл плагина
Установка -> Распаковка `.hm` -> Создание `venv` -> `pip install` -> Запуск процесса (Subprocess) -> Healthcheck loop -> Остановка.
