# Home.Media

Модульная медиаплатформа для Synology NAS с плагинной архитектурой.
Каждый плагин — отдельный Python-процесс с собственным venv и веб-интерфейсом.

[![core tests](https://github.com/tro9n4ik/HM/actions/workflows/tests.yml/badge.svg)](https://github.com/tro9n4ik/HM/actions/workflows/tests.yml)

**Что это:** ядро-платформа, которое запускает, останавливает и обслуживает плагины.
Плагины добавляют функции: Telegram-бот, поиск фильмов, торренты, камеры и т.д.
Ядро берёт на себя авторизацию, назначение портов, health-проверки, логи,
резервное копирование настроек и reverse-proxy до UI плагинов.

## Возможности

- **Zero-config deploy** — не нужно редактировать файлы .env, всё генерируется само
- **Установка плагинов из .hm пакета** — загрузка файлов через веб-интерфейс
- **Автозапуск** — плагины стартуют сами при рестарте NAS
- **Управление через UI** — настройка портов, зеркал PIP прямо в браузере

## Быстрый старт

1. Распакуйте исходники в `/volume1/docker/hm3-syn/`
2. Откройте **Synology Container Manager** → Проекты → Создать → выберите папку
3. Нажмите **Deploy**
4. Откройте: `http://NAS_IP:8142` и создайте аккаунт администратора в Setup UI.
