# Example Plugin (Пример)

Демонстрационный плагин для понимания структуры плагинов платформы Home.Media.

## Назначение
Служит заготовкой/примером (SDK) для разработчиков. Демонстрирует базовые возможности `plugin_sdk.py`, создание веб-интерфейса, обработку простых API-запросов и интеграцию с ботом (в манифесте прописано свойство `bot_menu`).

## Структура
- `manifest.json` — Описание плагина, версия, настройки (`config_schema`).
- `main.py` — Точка входа, FastAPI приложение `PluginApp`.
- `web/` — Статические файлы для фронтенда плагина (`index.html`).
