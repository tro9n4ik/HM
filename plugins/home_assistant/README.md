# Home Assistant Plugin

Плагин интеграции с Home Assistant, позволяющий управлять умным домом как через веб-интерфейс, так и через Telegram-бота.

## Назначение
Предоставляет интерфейс для контроля сущностей (свет, климат, переключатели) и включает встроенный конструктор инлайн-меню для Telegram-бота (кнопки, привязка сущностей, эмодзи).

## Настройки (Через панель администрирования Home.Media)
- **HA URL** (`ha_url`) — Адрес Home Assistant (например, `http://homeassistant.local:8123`).
- **HA Token** (`ha_token`) — Долгосрочный токен доступа (Long-Lived Access Token) к API Home Assistant.
- **Инлайн меню Telegram** (`bot_inline_menu`) — JSON-структура кнопок, генерируемая в конструкторе плагина.

*Другие настройки (поллинг, скрытие сущностей и т.д.) также доступны в конфигурации, но настраиваются опционально.*

## Эндпоинты API
- `GET /api/entities` — возвращает список отфильтрованных сущностей (`light`, `switch`, `climate`, `sensor`) для UI.
- `POST /api/control` — управление состоянием сущностей (toggle, set_temperature, play/pause).
- `GET /api/menu-layout` — получение структуры инлайн-меню для конструктора.
- `POST /api/menu-layout` — сохранение разметки, созданной в конструкторе.
