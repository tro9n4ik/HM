# Telegram Bot Plugin

Единый хаб для взаимодействия с платформой Home.Media через мессенджер Telegram.

## Назначение
Этот плагин регистрирует Webhook/Polling для бота и маршрутизирует команды/callback-сообщения к другим плагинам. Он агрегирует меню других плагинов, если они содержат свойство `bot_menu` в их манифесте.

## Настройки (Через панель администрирования Home.Media)
- **Telegram Bot Token** (`BOT_TOKEN`) — Токен авторизации, полученный у @BotFather.
- **Allowed Users** (`ALLOWED_USERS`) — JSON-список ID пользователей Telegram, которым разрешен доступ к боту.

## Взаимодействие с другими плагинами
Плагин Telegram маршрутизирует вызовы. Например, если в Home Assistant настроено инлайн-меню, то Telegram Bot перехватывает клик по кнопке с префиксом (вида `ha_...`) и перенаправляет HTTP POST запрос на `/bot/callback` в Home Assistant.
